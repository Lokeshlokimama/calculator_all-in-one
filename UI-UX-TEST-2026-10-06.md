# UI and UX test report — 6 October 2026

Local preview: http://127.0.0.1:4173/. No deployment or push performed.

## Coverage
- In-app Chromium browser, viewport simulations at 320, 390, 768 and 1440 pixels.
- Homepage plus 42 content pages checked at 320, 768 and 1440 pixels (129 page/viewport combinations).
- Phone navigation opened and used on calculator and PDF page systems; menus checked down to 320 pixels. Desktop and mobile screenshots saved in the parent workspace.
- Search with keyboard submission, category filtering, no-result feedback, visible keyboard focus, animation pause/resume.
- EMI empty-input validation, 500,000 / 10% / 60-month calculation (10,623.52), and complete 60-row repayment schedule.
- EPF worked example checked during theme verification: one-year corpus 29,234.
- Synthetic PDF selected: preview loaded, text export generated, page image rendered at 918 × 1188, download controls shown. Clear/reset worked. Corrupt PDF tested and rejected with conversion disabled.
- Build/link/syntax checks passed; 66 regression tests passed after the PDF error-state change.

## Issues fixed
1. Mobile calculator menu was covered by the header search. Raised the menu stacking level.
2. PDF and calculator dropdowns could extend off-screen on narrow phones. Right-aligned their menu controls, bounded dropdown width, and added internal scrolling for long menus.
3. Small touch controls and small input text. Increased key controls to 44px and phone input text to 16px.
4. Fixed animation toggle could cover form controls. Moved the toggle into normal document flow on phones.
5. Mobile menus lacked Escape/outside-click dismissal. Added both and restored summary focus on Escape.
6. Corrupt PDF misleadingly suggested retrying conversion. Parsing failures now disable conversion and request another/repaired file; preview-only failures may still allow conversion.

## Limits
These are viewport simulations, not physical iPhone/Android or Safari/Firefox tests. Not every calculator input combination was exercised through the UI; regression tests cover additional calculation cases. No full screen-reader audit performed. Download event capture timed out in the browser tool, so generated export controls and previews are verified, but saved-file completion and opening downloaded files remain unverified. Reduced-motion behavior is implemented in CSS/JavaScript; OS preference emulation was not available for a live check.
