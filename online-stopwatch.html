What this tool does

Press Start to begin timing, Pause to stop, and Start again to continue from where you left off. Reset sets it back to zero. The display shows hours, minutes, seconds and hundredths of a second.

Good uses

  • Timing study sessions or Pomodoro blocks.
  • Rehearsing a talk to fit a time slot.
  • Timing exercise intervals or rest periods.
  • Measuring how long a routine task really takes before estimating it.

Accuracy

The stopwatch counts in hundredths using the browser’s timer. It is fine for everyday timing, but browsers slow down timers in background tabs and on phones when the screen locks, to save battery. If you switch tabs or lock your phone for a long time, the displayed time can fall behind the real time. Keep the tab visible for best results, and do not use it where precise timing matters, such as official sports timing.

Limitations

There is no lap or split button, and the time is not saved if you close or reload the page.

FAQs

Does the stopwatch keep running in another tab?

It keeps running, but browsers may slow it down in background tabs, so it can fall behind.

Does it have laps?

No. Pause and note the time for a simple split.

Will it reset if I refresh the page?

Yes.

How precise is it?

It displays hundredths of a second; real accuracy depends on the browser keeping the tab active.

Can I use it as a countdown timer?

No, it counts up only.
