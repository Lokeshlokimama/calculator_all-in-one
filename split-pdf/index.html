Review note

Page extraction

Use the viewer page numbers, not printed numbers inside the document, when entering ranges. Always confirm that the downloaded PDF contains the intended pages.

How to choose the right PDF pages

Splitting is safest when you know the exact viewer page numbers and understand what must stay together in the final file.

1

Use viewer page numbers

Enter the page numbers shown by your PDF viewer, not printed page numbers in headers or footers. Printed numbers can restart or skip pages in long reports.

2

Keep related pages together

If a table, signature, diagram, or explanation continues onto the next page, include the full range so the extracted PDF still makes sense.

3

Verify before sharing

Open the downloaded file and confirm that confidential pages were removed and required pages were not accidentally left out.

Useful page-range examples

Range syntax

Use 1-3 for the first three pages, 2,5,9 for individual pages, or 1-2,6-8 for multiple sections. The tool creates a new PDF and leaves your original file unchanged. If a document contains sensitive information, check the final file carefully before upload or email.

FAQs

How do I enter page ranges?

Use commas and hyphens, for example 1-3,5,8-10.

Will the original PDF be changed?

No. A new PDF is created in the browser.

Can I split encrypted PDFs?

No. Unlock the file first if you own it and have permission.
