What this tool does

Choose how many UUIDs you need, from 1 to 100, and generate. Each appears on its own line, ready to copy. They are created locally using the browser’s secure random number generator (Web Crypto).

What a version 4 UUID is

A UUID (universally unique identifier) is a 128-bit value written as 32 hexadecimal digits in five groups: 8-4-4-4-12. In version 4, 122 of those bits are random. The 13th digit is always 4 (the version), and the 17th is 8, 9, a or b (the variant).

Example: 6f290498-119c-4eac-9a14-62b3664d8f70

How unique are they?

With 122 random bits there are about 5.3 × 1036 possible values. You would need to generate around a billion UUIDs every second for about 86 years to reach a 50% chance of a single duplicate. In practice, collisions are not a concern for normal applications, but they are not mathematically impossible, so databases should still enforce uniqueness.

When to use something else

  • UUIDs are identifiers, not secrets. Do not use one as a password or a long-lived security token.
  • Random UUIDs do not sort by creation time, which can slow some database indexes. Version 7 UUIDs, which start with a timestamp, are designed for that case; this tool generates v4 only.

FAQs

Are these UUIDs truly random?

They use the browser’s cryptographically secure random number generator.

Can two UUIDs ever be the same?

It is astronomically unlikely but not impossible.

Are generated UUIDs stored?

No. They exist only in your browser tab.

What is the difference between UUID and GUID?

GUID is Microsoft’s name for the same format.

Can I generate v1 or v7 UUIDs?

Not here; only version 4.
