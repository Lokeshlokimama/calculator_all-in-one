## Read the rate as carefully as the amount

### Verify the conversion direction

Suppose an illustrative reference rate is 0.80 target units for one source unit. Converting 100 source units gives 80 target units. Converting 80 target units back with the reciprocal rate of 1.25 returns 100 source units before rounding. Using 0.80 in both directions would incorrectly produce 64. This example uses an invented rate to explain multiplication; it is not a quote for any currency pair today.

Always read the displayed pair from left to right. A symbol alone can be ambiguous because several currencies share the dollar sign. Preserve the three-letter currency codes with a result you copy into a budget. Swapping the pair changes the question being answered; it does not merely change the result's visual label.

### Compare a reference estimate with an actual quote

If a service says a recipient will receive 78 units for a total cost of 100 source units, the effective rate is 0.78. Against the hypothetical 0.80 reference rate, the difference is two target units. That difference could combine a rate margin and a separately charged fee. The converter does not identify the service's charging structure. Compare the total paid and the final amount received from the provider's own quote.

The update timestamp matters when a rate comes from a cached response. A successful calculation does not mean that a fresh network request just completed. If the displayed information is too old for your task, wait for a new rate or obtain another current reference. Do not repeatedly switch currencies to make an outdated response look current.

### Recover from an unavailable rate

Check the network connection and the amount first. Missing, invalid, stale, or non-finite rates should produce an error rather than a guessed conversion. Save the pair and the timestamp, not only the numerical result. The display-currency setting elsewhere on the site labels arithmetic amounts; changing that setting does not exchange or revalue an existing loan, salary, or invoice. Use this actual converter when your task requires a rate-based conversion between currencies.
