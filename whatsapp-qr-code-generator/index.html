What this WhatsApp QR generator does

The tool formats a wa.me direct chat link and renders it as a QR code. A scanner can open WhatsApp with the phone number and message you prepared.

Where it works well

Use the QR on product packaging, business cards, restaurant tables, event stalls, real estate flyers, and support posters where typing a number would be slow.

Phone number formatting

Use the country code without plus signs or spaces for the most reliable result. For India, a number usually begins with 91 followed by the 10-digit mobile number.

Safety checks

Scan-test the QR before printing. Confirm it opens the right chat and message. Replace the QR if the phone number changes or if the campaign message is outdated.

Method and limitations

The QR payload is assembled from the fields shown on the page and rendered locally in the browser. Static QR codes do not provide scan analytics, editable redirects, payment confirmation, or account-based history. See the editorial standards and site disclaimer for the limits of these tools and how to report a problem.

FAQs

Does the QR send a message automatically?

No. It opens WhatsApp with a prepared message. The user still chooses whether to send it.

Should I include the plus sign?

For wa.me links, use country code and number without the plus sign.

Can I use it on a shop poster?

Yes. Test the final poster at the actual print size.

Does it work without WhatsApp installed?

The link may open a browser prompt, but the best experience requires WhatsApp.

Can I change the message later?

Static QR codes cannot change. Generate a new QR if the message changes.

Is the QR generated locally?

Yes, the QR image is rendered in the browser.

Create a chat shortcut with a clear purpose

Check the international number before generating

The phone field should contain the complete international number, including the country code. The payload uses a wa.me address followed by digits. This page strips non-digit formatting characters, which can make an entered plus sign or spacing harmless, but it cannot infer a missing country code or determine whether the final number belongs to the intended person. Inspect the resulting digits rather than assuming the original formatting proves correctness.

Do not add a national trunk prefix merely because it appears in a locally printed phone number. Confirm the internationally formatted contact number with the intended recipient. A technically valid link to the wrong number is still the wrong contact route. The generator does not query WhatsApp's account directory or verify ownership of a business number.

For a safe layout test, use a placeholder number supplied by your own test plan and avoid sending messages to it. Verify the structure without contacting an unrelated person. Before a real sign is published, the authorised number owner should confirm the contact destination and the purpose of making the number publicly accessible.

Write a message that helps the recipient respond

A short prefilled message can state the user's likely task: “Hello, I would like the opening hours” or “Hello, I have a question about order reference ABC”. This reduces ambiguity while leaving the visitor free to edit the message. Avoid putting a customer's private information, a password, payment details, or confidential order history in publicly distributed QR artwork. The prefilled text is part of the readable link.

The tool URL-encodes message characters so spaces, punctuation, and non-English text can travel in the URL. A space may appear as an encoded sequence in the payload while the chat composer displays ordinary text. Do not manually replace those encoded characters in the generated URL. That can change how the link is interpreted, especially when a message contains an ampersand or question mark.

Long messages increase the amount of text encoded in the QR and can make it denser. Put the essential request in the prefill and allow the user to supply personal details inside the conversation when appropriate. A QR sign is an entry point to a discussion, not a replacement for a full support form with validated fields.

Distinguish opening a chat from sending a message

Scanning or following the link can open a chat interface when the device and account support it. It does not automatically send the prepared message. The visitor must review the recipient and text and decide whether to send. The generator neither confirms delivery nor records whether a conversation began. A successful QR preview is not evidence of a customer interaction.

WhatsApp's official click-to-chat feature works through the application or web experience as supported on the receiving device. A phone without a suitable application setup may show a different intermediate prompt from a signed-in desktop browser. Test the intended journey on the devices your audience actually uses, rather than assuming one desktop preview covers every situation.

Prepare a public sign responsibly

Place the purpose and number owner's identity beside the code so visitors know what the shortcut opens. If the sign says “support”, confirm that the receiving number is meant for that channel. The QR itself does not establish business identity, response time, staff availability, or permission to contact an individual outside their expected context.

Retain a readable alternative contact route for people who cannot or do not want to scan. That could be an approved phone number or a website contact page. Choose the alternative based on the actual support process rather than adding channels that nobody monitors. Clear expectations improve the experience more than a complicated prefilled message.

Test changes and replace old artwork

When the receiving number changes, every static printed copy continues to contain the old number. Generating a replacement on this page does not alter previously saved images. Identify the old files and signs before publishing new artwork. If only the prefilled message changes, the same replacement rule applies: the text is inside the code, not stored in an editable account here.

Scan the final-sized print and inspect the recipient and composer text without sending a message. Check that cropping has preserved the code's border and that the image has not been stretched. Keep the original number and message with the design file so another staff member can audit it before the next print run.

Reference: WhatsApp official click-to-chat instructions. Examples above use this calculator’s assumptions.
