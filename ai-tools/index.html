How the image check works

The workflow is deliberately short. The score is one signal in a broader verification process.

1.0

Select an image

The browser checks the file type and 5 MB limit, then shows a local preview before anything is sent.

2.0

Request analysis

The image is sent to the site’s server endpoint. API credentials stay on the server and the uploaded file is held in memory only for the request.

3.0

Read the result carefully

A verdict, confidence score, and explanation can guide a closer review. None of them establish identity, intent, or legal fact.

Privacy before prediction

No file storage

Calculator All-in-One does not save checker uploads. When a provider is configured, the selected image must be transmitted to that provider for analysis and may be subject to the provider’s own processing terms. Avoid uploading confidential, intimate, medical, financial, or identifying images.
