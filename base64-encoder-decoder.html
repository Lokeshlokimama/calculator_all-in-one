Encode or decode

What this tool does

Paste text and choose Encode to get its Base64 form, or paste Base64 and choose Decode to get the original text back. Text is first converted to UTF-8 bytes, so Hindi, Tamil, emoji and other non-English characters work correctly in both directions.

What Base64 is

Base64 represents any data using 64 safe characters: A–Z, a–z, 0–9, + and /, with = for padding. It is used to carry binary or special-character data through systems that only handle plain text, such as email attachments, data URLs, JSON fields and HTTP Basic authentication headers. Every 3 bytes become 4 characters, so encoded data is about 33% larger.

Worked examples

  • “Hello” encodes to SGVsbG8=
  • “नमस्ते” encodes to 4KSo4KSu4KS44KWN4KSk4KWH (18 UTF-8 bytes become 24 characters)

Base64 is not encryption

Anyone can decode Base64 instantly. Never use it to hide passwords, API keys or personal data. If you find credentials stored as Base64, treat them as exposed. For secrecy you need real encryption, and for passwords, a hashing algorithm designed for passwords.

Troubleshooting decode errors

  • Make sure you pasted the whole string, including any = at the end.
  • URL-safe Base64 uses - and _ instead of + and /; replace them before decoding.
  • If the original data was a file such as an image, decoding it as text will not produce readable output.

Privacy

Encoding and decoding happen in your browser; nothing is uploaded.

FAQs

Is Base64 secure?

No. It is an encoding, not encryption, and can be reversed by anyone.

Does it support Hindi and other Indian languages?

Yes. Text is encoded as UTF-8 first.

Why does my decoded text show an error?

The input may be incomplete, URL-safe Base64, or not text at all.

Why is Base64 longer than the original?

Every 3 bytes become 4 characters, about a third larger.

Can I encode files?

This tool encodes text. Files need a file-to-Base64 tool.
