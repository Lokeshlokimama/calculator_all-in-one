Important limitation

Raster compression

The compressed PDF may no longer contain selectable text, links, bookmarks, signatures, or form fields. Do not use this method for contracts, official records, signed PDFs, or accessibility-critical documents.

FAQs

Why could the file get larger?

Some PDFs are already optimized. Rasterizing them can add image data and increase size.

Does it preserve searchable text?

Usually no. This compression creates image-based pages.

What setting should I choose?

Start with Balanced, then open the output and check readability.

Compression is useful only when the result stays readable.
